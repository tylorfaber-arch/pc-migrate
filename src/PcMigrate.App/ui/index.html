Asking the drives…

Many USB adapters and enclosures don't pass a drive's health through; those show as unknown. Connecting the drive with a different adapter, or inside a PC, usually works.

Technician mode

For doing jobs for clients. Each backup and move asks for the client's name and job number, and saves a printable report for the client with your business details: what was moved, what's still to do, and anything that couldn't be copied.

Scheduled backup

Keeps a backup of this PC up to date by itself, even when nobody is signed in. Each time, only new and changed files are copied, so it's quick. The backup can be loaded onto a new PC like any other.

Make a rescue USB

For a PC whose Windows won't start: plug the stick in, start the PC from it, and pc-migrate opens so its files can be saved. Built from this PC's own Windows, so it works with Secure Boot.

Get deleted files back

Finds files deleted from a drive (even after the Recycle Bin was emptied) and copies them somewhere safe. The sooner after deleting, the better the odds.
